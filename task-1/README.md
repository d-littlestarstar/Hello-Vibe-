# 灵蛇绘卷 · Fortune Snake 🎨🐍

这是 Hello-Vibe 仓库中的第一个 Vibe Coding 实验项目。

一个融合传统年味视觉风格与现代前端技术的创意小游戏：
- React + Vite 构建
- TailwindCSS 设计风格
- 国风 UI + 动效系统
- 关卡模式 + 连珠机制 + 无敌金身

---

## 🎮 项目简介

《灵蛇绘卷》是一款基于“贪吃蛇”玩法的创意改造版本。

核心特色：

- 🧧 吃“福”字得分
- 🧨 动态障碍物（高难模式）
- 🏮 随机灯笼触发无敌状态
- ✨ 墨韵粒子特效
- 🎴 国风卷轴展开动画
- 🏮 年味 UI 设计体系

目标不是简单复刻游戏，而是：

> 用 Vibe Coding 的方式，快速表达想法，
> 用 AI 协作生成结构，
> 用迭代打磨视觉与体验。

---

## 🧠 技术栈

- React 18
- Vite
- Tailwind CSS
- Babel Standalone（浏览器 JSX 运行）
- LocalStorage 高分记录

---

## 🚀 本地运行

```bash
npm install
npm run dev
```

然后在浏览器打开：

```
http://localhost:5173
```
